# 积木工坊 · 四种世界，自动拼接

每轮四张卡片分别提供森林、雪地、熔岩和沙漠主题；主题会与不同路线、难度和机关组合。点击一次就把选中的完整场景接到路线末端。

## 顺路采集，自动制作和升级

跑酷时靠近金色材料就会自动拾取。起点和各挑战区的永久落脚点都有材料，沿原路线走即可，不增加采集按钮、背包或配方菜单。

第一批 3 块材料会自动消耗并制作 Lv1 护盾；再收 6 块升级 Lv2，再收 9 块升级 Lv3。角色会戴上头盔，并出现青色、蓝色、金色护盾，分别能够抵挡每段 1、2、3 次机关碰撞。抵挡后有短暂保护时间，防止同一次接触连续扣除次数。进入下一段、重试或重新开始跑酷时会补满护盾。

护盾抵挡机关，掉落和熔岩池仍会送回本段入口。已采集的材料不会因重试或重新载入而重复领取。成长会自动保存在浏览器中，导出场景时一并备份；导入成长数据会合并已有进度。四选一拼接继续直接使用，材料用于自动制作和升级护盾。

同一主题现在有四种实体地形，共十六种：

| 主题 | 地形 |
| --- | --- |
| 森林 | 巨木林地、峡谷栈道、林间遗迹、树冠群岛 |
| 雪地 | 冰峰雪岭、冰裂峡谷、冰晶群岛、冰洞回廊 |
| 熔岩 | 火山熔池、裂谷熔河、玄武岩柱、废弃熔炉 |
| 沙漠 | 阶梯金塔、砂岩峡谷、失落神庙、绿洲浮岛 |

地形改变实体山体、悬岛、峡壁、遗迹和平台厚度。路线独立随机选择回转弯道、绕塔盘旋、上下穿插、折返山路、山脊高架或回廊环线，并改变长度、间距和高度。每轮四张卡片的路线形态各不相同；同主题最近三次选过的地形不会立即重复，也会避开上次的路线及机关顺序。

每张新卡片保留一种主题特色机关，再随机搭配一至两组其他机关；机关顺序、区段长度、位置和节奏也会变化：

- 森林滚木会沿道路滚来，碰撞需要提前起跳越过。启动前有提示灯，两轮之间可安全等候。
- 雪地蓝色滑面有真实惯性，松手后还会滑行，反向按键可以更快刹车。滑面两侧有护栏，入口和出口各留至少四格不打滑的雪地；连接弯道也使用不打滑的雪地。
- 熔岩喷口先亮灯预警，再喷火，最后熄灭。火柱高于跳跃极限，需要等待熄火窗口通过。
- 沙漠升降压柱会定时落下，完全抬起后可以穿过。

每种难度都使用实际角色物理验证，检查可重复的起步时机及前后 0.07 秒的容差。完整拼接段会再次回放，包含随机相位、反向路线、高低层、等待和冰面减速。

- 森林：草地、木桥、巨树、灌木和萤火。
- 雪地：积雪平台、冰蓝步道、冰峰和飘雪。
- 熔岩：黑曜石步道、火山、发光岩缝、熔岩池和余烬；落入熔岩会回到本段入口。
- 沙漠：砂岩步道、金字塔或方尖碑、残柱、仙人掌与浮尘。

不同主题有独立的实体地貌、机关配色、天空和光照。观察新场景时采用该主题的氛围，跑酷时随当前段落切换。装饰避开跑道周围七格宽的区域；只给已有永久平台加厚，不填平塌板或移动台的缺口。新主题完成装饰后仍须通过整段物理校验。

底部仍然只有四张卡片，分别提供简单、普通、普通、困难的混搭场景。每段包含两到三种不同机关，卡片展示实际组合；点击一次就接上一整段，选完自动换新。混搭段之间的入口、出口、高度和转弯路线自动衔接。

每段内部有多次转弯和高低台阶；山脊路线沿长距离高架穿行，折返路线在多个方向切换，回廊路线围绕宽阔庭院展开。上下穿插的挑战层至少相距十二格，留出结构和跳跃空间。实体连接通道宽三格，转角有宽平台及前进箭头，段落接口统一保持五格宽。

机关包括节奏闸门、尖刺、旋转横杆、摆锤、塌陷地板和移动平台。不同机关之间通过实体弯道与台阶连接，前后有稳定落脚区。塌陷区之后不会直接放置需要停留等候的机关。旧版直线混搭保留原来的六格连接平台。

## 可通行校验

生成器使用游戏里的角色速度、跳跃高度、固定时间步长和碰撞函数进行检查。

- 每种难度的挑战区先获得可重复的物理通过路线，并验证起步时机前后 0.07 秒的容差。
- 每张混搭卡片还会进行整段物理回放，包括连接台阶、稳定区、跳跃、等待机关和平台搭乘。
- 检查不同起步时间、反向行进、上行和下行连接。没有通过检查的候选会被重新抽取。
- 机关之间留有永久的等待区，因此可等待下一轮通行窗口再继续前进。

通行路线可能需要观察时机、起跳或连续前进。该校验针对当前游戏的物理参数，不依赖玩家自动通关。

## 随机结果和存档

每张卡片包含确定的随机参数、地形编号及生成版本。预览、实际搭建和存档使用同一个组合；重试、撤销、重做、导入和重新打开都不会重新抽取已搭好的机关、主题或地貌。塌陷地板在本段重试时恢复。已有主题存档保留原布局和机关，新卡片才使用新生成版本。

路线自动保存到当前浏览器。导出 JSON 可备份或换设备导入，旧版路线也可以继续导入和拼接。已有混搭配方保留旧布局；新卡片将路线形态一并保存在配方中。原自由搭建存档单独保留。

## 启动和操作

```sh
python3 -m http.server 58347 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:58347/。依赖随附，运行不需要 CDN 或第三方 API。

点卡片或按数字 1–4 选当前候选。点“开始跑酷”后，WASD / 方向键移动，空格跳跃，拖动观察；触屏用摇杆和跳跃键。进入一段后自动存档，失误回本段入口。Esc 返回继续拼接。右上角的四格图标可载入不同难度的混搭示例。

```sh
npm run check
npm test
```

包括原有十八种场景和六种机关的回归检查、192 个旧式混搭布局的 384 次整段回放、288 个立体布局的 576 次整段回放、288 个主题布局的 576 次整段回放，以及 288 个特色机关布局的 576 次整段回放。普通、主题和特色机关世界各检查完整拼接的 12 段。额外验证滚木运动及跳跃碰撞、冰面滑行距离和反向刹车、干燥出口减速、不同高度冰面的隔离、喷火预警和熄灭窗口、升降压柱、等待平台、四选一和存档兼容。

新变化生成器另检查 60 种挑战区变体及起步容差、16 种真实地形、6 种不同路线、80 种机关顺序、576 个组合布局的 1152 次物理回放，以及连续 16 段（包含相邻结构、跨排反向路线和熔岩池）的完整世界回放。同时验证同主题地形不立即重复、四张卡片路线各异、预览及存档可复现，以及旧配方继续保留原样。

成长检查包括自动消耗 3/6/9 材料、存档去重及合并、追加路线后的材料标识稳定、真实机关碰撞下的护盾次数和保护间隔、段落补充保护、不同楼层的拾取隔离，以及 384 个永久安全拾取点。起点首次升级只需要沿安全平台前进。

## 界面和特效

界面采用奶油白面板、暖金主按钮和四种主题卡片。卡片显示实际地形缩略图、路线、机关与难度，仍只需四选一。材料、护盾等级和自动升级进度集中显示；跑酷面板增加剩余保护图标。

材料拾取带有飞向角色的金色光点；自动制作或升级时显示消耗、等级和实际保护次数，并播放粒子及扩散光环。护盾使用柔和边缘光，抵挡机关时出现脉冲效果；拼接场景有落点光环。特效使用共享粒子池，不参与碰撞和资源计算，并适配减少动态效果的系统偏好。

## 移动端操作

手机布局保留底部四张场景卡片；顶部只显示品牌、更多工具和开始/返回按钮，撤销、重做、导入、导出、示例和拍照收在工具菜单。交互区域至少为 44 像素，适配 320 像素窄屏、横竖屏、动态视口及刘海/底部安全区。镜头按实际顶部和底部面板的边界取景，旋转屏幕时重新适配。

跑酷时使用紧凑状态面板、左侧摇杆和右侧跳跃键，空白处拖动控制视角。摇杆提供死区、拖出边界后的方向限制和按压反馈；每个控件独立跟踪触摸手指，移动、跳跃与视角可以同时操作。取消触摸、失去指针捕获、旋转屏幕或切到后台会清除输入，避免继续移动或跳跃。小屏窗口也会显示屏幕控件。移动布局把三维画布像素比限制为 1.5、阴影贴图限制为 1024，以减少绘制负担。

`node tests/touch-controls.test.mjs` 验证双指独立操作、额外手指误释放、取消/捕获丢失、死区、边界及中断后恢复。
